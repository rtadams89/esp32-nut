ESP32-NUT INSTALLER

Firmware Installation

  1. Connect your ESP32 board to the computer via USB cable.
  2. Make sure to use a data cable (not just for charging).
  3. Click the button for your board below and select the serial port corresponding to your device.

ESP32-S3 · Wi-Fi

ESP32-P4 · Ethernet (chip revision v3.1+)

ESP32-P4 · Ethernet (chip revision before v3)

ESP32-P4: esptool.py chip_id or the serial boot log (“chip revision: v1.3”) tells the revision. An image for the wrong revision does not boot: flash the other one.

Supported browsers: Chrome, Edge, Opera.

Requirements: Web Serial API enabled.
